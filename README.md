# Fragrance Collection Tracker 🔐

A comprehensive Spring Boot application demonstrating advanced Spring Security implementation with user management and personal fragrance collections.

## Core Security Features:
- **JWT Authentication & Authorization** - Secure API endpoints
- **User Registration & Login** - Complete user management system
- **Password Reset Flow** - Email-based password recovery system
- **Role-based Access Control** - Different permissions for users
- **User-Product Relationship** - Each fragrance linked to specific users

## Technical Implementation:
- Spring Boot 3.x with Spring Security
- PostgreSQL database with proper relationships
- JWT token-based authentication
- Password encryption & validation
- RESTful API architecture
- Deployed on Heroku

## Advanced Security Features:
- Custom UserDetailsService implementation
- Password encoder configuration
- JWT filter chain integration
- Protected endpoints with user context
- Secure password reset tokens
